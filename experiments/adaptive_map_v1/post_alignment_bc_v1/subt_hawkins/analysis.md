B 的退化、MAD/SVD、质量和自适应拒点字段为 OFF 快路径的未计算零占位，不能把零解释为
没有退化或没有坏点。六次 `map_update_skipped` 均为 0，因此 20 点整帧入图门槛没有触发；
本轮 C 的变化来自点级质量/量程筛选、退化帧 invalid-quality 分类与候选排序，而不是整帧
停止建图。

C 确实显著减少了入图量，同时提高并稳定了 ATE。当前证据支持：冻结 C 整体策略在
SubT Hawkins 上比修正后内部 OFF 基线更稳健。它尚不能证明：收益专门来自“有邻域匹配
失败/无邻域”分类；因为质量阈值、80 m 自适应量程和退化排序也同时开启，最终地图点数也
明显不同。更不能把少入点本身当成地图质量改善的证明。
